# Celebal Summer Internship Assignments 🚀

This repository contains a collection of weekly assignments and the final project completed during my summer internship at **Celebal Technologies**. The tasks cover a wide range of concepts from Python programming and data structures to machine learning model deployment and advanced topics like RAG-based chatbots and anomaly detection in network traffic.

---

## 📅 Weekly Task Overview

### ✅ Week 1: Pattern Printing
- Created lower triangular, upper triangular, and pyramid patterns using the `*` character in Python.

### ✅ Week 2: Singly Linked List (OOP)
- Implemented a singly linked list in Python using Object-Oriented Programming.
- Included functionality to:
  - Add nodes at the end
  - Print the list
  - Delete the nth node
- Exception handling for:
  - Deletion from an empty list
  - Index out-of-range errors

### ✅ Week 3: Data Visualization
- Visualized key aspects of a dataset using Python libraries like **Matplotlib** and **Seaborn**.
- Dataset used: *Titanic Dataset* (Kaggle)

### ✅ Week 4: Exploratory Data Analysis (EDA)
- Performed a comprehensive EDA on the Titanic dataset.
- Explored:
  - Data distribution
  - Missing values
  - Outliers
  - Variable relationships
- Visualizations used: Histograms, Box Plots, Heatmaps

### ✅ Week 5: House Price Prediction – Data Preprocessing
- Carried out data cleaning, handling missing values, encoding categorical features, and feature scaling.
- Dataset used: [House Prices - Advanced Regression Techniques](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques)

### ✅ Week 6: Model Evaluation & Hyperparameter Tuning
- Trained ML models like Linear Regression, Random Forest, and XGBoost.
- Evaluated using metrics: Accuracy, Precision, Recall, F1-Score
- Performed hyperparameter tuning using:
  - `GridSearchCV`
  - `RandomizedSearchCV`

### ✅ Week 7: Model Deployment using Streamlit
- Built an interactive web app using **Streamlit** to deploy a trained ML model.
- Users can input data and receive predictions in real-time.
- Included data visualizations for better understanding of model output.

### ✅ Week 8: RAG-based Q&A Chatbot
- Implemented a Retrieval-Augmented Generation (RAG) Q&A system.
- Combined document retrieval with a generative model for intelligent responses.
- Dataset used: [Loan Approval Dataset from Kaggle](https://www.kaggle.com/datasets/sonalisingh1411/loan-approval-prediction)

---

## 🎓 Final Project: Anomaly Detection in Network Traffic
- Built an unsupervised ML solution to detect anomalies in network traffic.
- Techniques used:
  - Isolation Forest
  - Autoencoder Neural Networks
- Dataset: KDD Cup 1999 (`corrected.gz`)
- Goal: Detect suspicious patterns potentially indicating security threats.
